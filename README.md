# Game Focus

Tu centro de juego para Android.

## Descargar
Ve a la sección **Releases** (a la derecha o abajo de esta página) y descarga el archivo `.apk` de la última versión.

## Requisitos
- Android 10 o superior
- Para instalar el APK, permite "instalar apps de fuentes desconocidas" cuando Android te lo pida.
